LOGIFLOW VERSION 3 — CLASSROOM PROTOTYPE

Open index.html in a modern browser (Chrome, Edge, Firefox, Safari).
No installation or internet connection is required for the core prototype.

WHAT'S NEW
- Interconnected dashboard, inventory, orders, customers, deliveries, AI Prompt Lab, reports, and settings.
- Create fictional customers, products, orders, and simulated shipments.
- Inventory quantity is deducted when an order moves into Processing, Packed, or Completed.
- If an order is cancelled after stock deduction, the quantity is restored.
- Role-based prompt templates with operational sample data, copy, save, and prompt history.
- Manual HEX color fields and color pickers, preset palettes, live preview, editable navigation, and layout preferences.
- CSV exports for orders and inventory.
- Browser localStorage saves demo data and customization on the same browser/device.

IMPORTANT LIMITATIONS
- All records are fictional and intended for classroom demonstration.
- The AI Prompt Lab builds and saves prompts; it does not call an AI model or external AI API.
- Delivery tracking is simulated; there is no live GPS, carrier, or map integration.
- Data is stored locally in the browser. There is no backend, cloud database, login, or secure owner-only permission system.
- This is a front-end prototype, not a production-ready logistics platform.

DEMO SUGGESTION
1. Open Dashboard and review the overview.
2. Open Inventory and show the low-stock item.
3. Create an order for a product with available stock.
4. Change the order to Processing and show the inventory deduction.
5. Open AI Prompt Lab, choose Inventory Risk Analyst, and copy the generated prompt.
6. Open Settings and customize the HEX palette, then save.
7. Export a sample CSV from Reports.

To reset demo data, use the browser's site data/localStorage controls. Version 3 also retains settings separately from demo data.

V3.1 update: The Create Order customer field now accepts any typed customer name, with suggestions from existing customers. A new name is automatically added to Customer Directory when the order is created.
