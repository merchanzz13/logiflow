LOGIFLOW V3.1 — GITHUB PAGES DEPLOYMENT

This folder is prepared as a static website. The main page is index.html.

PUBLISHING CHECKLIST
1. Sign in to GitHub and create a NEW repository named logiflow-demo.
2. For a classroom demo, set the repository to Public. Do not upload private or real customer information.
3. Upload the CONTENTS of this folder to the repository's top level:
   - index.html
   - .nojekyll
   - APP_README.txt
   - DEPLOY_TO_GITHUB_PAGES.txt
   Make sure index.html is not buried inside another folder.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for GitHub Pages to finish. The published URL will be shown in Settings → Pages.
8. Open that URL in a private/incognito window and test the modules.

IMPORTANT DEMO LIMITATIONS
- This is a front-end classroom prototype.
- Demo records and settings are saved in each visitor's own browser (localStorage).
- Different testers do NOT share one common database; their changes will not sync.
- The AI Prompt Lab creates prompts but does not call an AI model/API.
- Delivery progress is simulated; there is no carrier or GPS integration.
- There is no login or secure owner-only access. Do not enter real personal, customer, or business data.
